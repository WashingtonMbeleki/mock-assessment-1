# Level 3 Python Assessment: Control Flow & Loops

Welcome to your Level 3 Python Assessment! This test evaluates your understanding of fundamental Python control structures: conditional statements (`if`, `elif`, `else`) and loops (`for`, `while`).

## Project Structure
- `assessment.py`: The file where you will write your code for the 5 questions.
- `test_assessment.py`: The test suite used to check your answers. **Do not modify this file.**

## Instructions
1. Open `assessment.py`.
2. Read the docstrings/instructions for each of the 5 functions and write your code inside them.
3. Run the tests in your terminal to check your progress:
   ```bash
   python -m unittest test_assessment.py
